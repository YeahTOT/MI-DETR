# Contributor Guide Design

**Goal:** Add a concise `AGENTS.md` contributor guide tailored to MI-DETR.

**Scope:** Cover repository layout, `.venv`-based setup, common train/validate/test commands, Python style conventions visible in the codebase, test file patterns, commit message style inferred from recent history, and guardrails for datasets, checkpoints, and generated `runs/` outputs.

**Approach:** Keep the guide in the 200-400 word range, prefer commands already documented in `README.md`, and avoid inventing tooling that is not configured in the repository.
